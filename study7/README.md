# Study 7: per-record classifiers, random vs temporal split (Section 5.5, Supplementary S12)
`PLAN_STUDY7.md` contains the plan and two dated addenda made before any model was run (UNSW-NB15 replaced by
X-IIoTID; chunked reading of Edge-IIoTset). `SEAL_STUDY7.sha256` is the final seal; the two superseded seals are
kept. `code/prepare_s7.py` builds the record arrays from the public datasets (paths are those of the machine that
ran the study; edit them), `code/run_s7.py` runs the 720 runs and `code/analyze_s7.py` the three sealed tests.
`results/prep_log.txt` records the preparation, including the discovery of the UNSW-NB15 test copies.
